Considered and parked

IdeaStatusEst.ActualWhy parked
Skinned-mesh rabbits Standard bone rig instead of a hand-built transform hierarchy. Parked8 h— The gait needs exact per-joint control; skin weights would only be fought.
Physics library Cannon/Rapier for collision instead of AABB push-out. Parked6 h— Flat ground and boxes. The game does not need one and would feel worse with it.
Build step / bundler Vite or esbuild. Parked2 h— Plain ES modules + import map works; a build step would slow iteration for no gain yet.
Loaded texture atlas for skins Authored PNGs instead of canvas generators. Parked10 h— Canvas generation is deterministic, seeded, adds zero download, and nothing can 404.
Rabbit-vs-rabbit collision So they cannot overlap during courtship. Idea2 h— Overlap is currently what makes the barging read as barging. Revisit if it looks wrong.
